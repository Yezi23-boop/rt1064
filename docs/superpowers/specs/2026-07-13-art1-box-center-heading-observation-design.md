# ART1 箱子中心与车头方向辅助观察设计

## 目标

科目二移动到黄色箱子的相邻观察格后，由 ART1 同时测量小车精确中心、指定箱子精确中心和车头四方向。MCU 先用小车中心修正 pose，再根据箱子中心计算真实观察点并做一次位置环微调，确认位置到位后才请求 ART2 分类。目标点扫描继续使用现有流程，本次不增加目标中心识别。

本版保持麦轮底盘现有固定 yaw，不为了观察箱子旋转。车头方向只下发和记录，不作为分类放行条件；协议保留方向字段，供后续增加主动面向箱子的观察状态复用。

本功能只在科目二观察节点按需运行，不参与普通地图帧，也不替代 IMU yaw。

## ART1 识别

- 增加 `DEBUG_OBSERVATION_ENABLE = False`。开启后无需 MCU 请求，ART1 在所有已识别 `B` 格中绘制黄色箱子中心、绘制小车中心到青蓝色车头半块的方向线，并按现有调试打印周期输出箱子格、中心坐标和车头方向；关闭后不执行这些额外调试识别。
- 调试开关只控制 IDE 绘图和串口终端打印，不通过 UART 向 MCU 发送观察样本，也不控制正式 `OBSERVE_REQ` 功能。
- MCU 发送 `OBSERVE_REQ row,col`。`row,col` 是当前待识别箱子的 `B` 格。
- ART1 复用现有绿色/青色色块连通域；青蓝色小半块即车头，不增加第三次颜色搜索。小车中心仍为两块中心的中点，车头方向由“绿色块中心到青色块中心”的主轴方向输出四方向。
- ART1 只在指定 `B` 格的内部 ROI 搜索黄色连通域，使用连通域质心得到箱子中心，不做全图黄色搜索。
- 箱子中心必须落在指定格内；小车中心、箱子中心和车头必须在同一帧全部有效，该帧才计入样本。
- 每次请求发送 3 个有效样本：

  ```text
  OBSERVE_SAMPLE index,car_col_q,car_row_q,box_col_q,box_row_q,heading
  ```

  坐标单位沿用 `1/100格`。第 3 个样本后结束本次请求。新请求清除旧锚点和样本计数。

## MCU 修正流程

科目二箱子扫描的原 `VPos -> VCtr -> VWait` 调整为：

```text
VPos -> VObs -> VAdj -> VChk -> VWait
```

1. `VObs` 收满 3 帧，对小车和箱子的 X/Y 分别取中值；车头方向三帧一致时记录该方向，不一致时记录为未知，但不阻止位置修正。
2. 根据最新 ART 地图 `C` 格和小车中心计算格内 offset，并立即重置 MCU pose；该修正只改变定位基准，不直接驱动车轮。
3. 根据当前观察方向计算理想小车中心：

   ```text
   小车在箱子左侧：ideal = box_center + (-1格, 0)
   小车在箱子右侧：ideal = box_center + (+1格, 0)
   小车在箱子上方：ideal = box_center + (0, -1格)
   小车在箱子下方：ideal = box_center + (0, +1格)
   ```

4. `VAdj` 使用现有位置环按 `ideal_player - measured_player` 做小范围 X/Y 微调，不新增运动控制器，不修改 PID 和里程计。
5. 到点稳定后进入 `VChk`，重新请求 3 帧。位置误差进入现有到点阈值后，才发送 ART2 `VISION_REQ`。
6. 验证仍未通过时只允许再微调一次；第二次仍失败、请求超时或箱子中心越出指定格时停车并进入 `E:BoxCtr`。车头无法稳定识别不单独导致停车。

## 边界与兼容

- 原 `CENTER_REQ/CENTER_SAMPLE` 保留，继续供发车、推箱前、重规划和返航使用。
- 普通 `MAP_BEGIN...MAP_END` 内容和周期不变；新增观察数据不塞入地图帧。
- 车头四方向只记录和调试，不写入 IMU yaw，不参与 20ms 姿态环，也不要求朝向箱子。
- 箱子中心只用于科目二分类观察，不改变 BFS 中箱子所在格，也不影响虚拟推箱判定。
- 目标点扫描继续使用现有 `VPos -> VCtr -> VWait`，不寻找目标精确中心。
- 离线地图、科目一、ART2 UART4 协议和返航逻辑保持不变。

## 验收

- ART1 能在指定 `B` 格内稳定输出箱子中心，并在蓝色车头朝四个方向时分别输出 `U/D/L/R`。
- `DEBUG_OBSERVATION_ENABLE=True` 时可脱离 MCU 查看中心十字、车头方向线和每秒调试输出；设为 `False` 后不产生持续额外识别开销。
- 无请求时帧率基本不变；观察请求期间只增加局部 ROI 识别开销。
- 小车停在名义观察格但与箱子实际中心错位时，MCU 能修正 pose 并移动到实际相邻一格的位置。
- 三帧中心中值验证通过后才触发 ART2 分类；错误箱子格或中心丢失不会继续分类。方向不一致记录为未知，但本版不阻止分类。
- OpenMV Python 语法检查、协议主机测试、科目二状态机测试和 Keil 编译全部通过。
