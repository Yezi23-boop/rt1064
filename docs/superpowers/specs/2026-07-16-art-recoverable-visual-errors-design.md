# ART 第一类可降级视觉错误设计

## 目标

精确视觉信息暂时不可用时，只要最新 ART 字符地图、粗格位置和底盘控制仍然可信，比赛流程不进入永久 `ERROR`，而是使用格点地图和 MCU 本地状态降级继续。

本设计只覆盖第一类错误：

```text
精确小车中心失败
视觉 yaw 失败
精确车箱观察失败
```

地图结构非法、对象跟踪冲突、路径不可达和底盘硬件错误不属于本设计范围。

## 基本原则

第一类错误不调用 `subject2_fail()` 或 `executor_set_error()`。降级过程中允许短暂停车切换状态，但不能进入需要人工重新启动的永久错误态。

精确视觉只是格内位置和低频 yaw 校准来源，不改变以下职责：

- ART 字符地图仍是 `C/B/T` 几何状态和上位机完成状态的权威来源。
- MCU 编码器 pose 用于连续运动和精确中心缺失时的格内位置保持。
- MCU IMU 是运动过程中 yaw 控制的主要来源。
- `OBSERVE_SAMPLE` 只服务推箱前精确准备位，不改变字符地图中的箱子状态。

## 直接降级条件

只有同时满足以下条件时，才允许跳过精确视觉并继续：

1. 存在一张新鲜、完整、合法的 ART 地图。
2. 地图中恰好存在一个 `C/+`。
3. 当前阶段需要的箱子仍位于预期格。
4. executor 和 IMU 没有硬件或内部执行错误。

任一条件不满足时，不得盲目继续运动，应转入后续的第二类“短暂停车重新同步”流程。

## 精确中心失败

### 发车中心

`WCTR` 收不到有效中心时，保持现有降级行为：

```text
固定向右移动 30cm
使用近似 home X
home Y 使用左通道 row=5 格中心
继续等待真实推箱地图
```

### 科目二观察中心

`VCtr` 收不到有效中心时：

```text
保留 MCU 编码器 pose
跳过 VAdj
直接进入 VTurn
```

不能因为中心缺失把 pose 强制重置为 `0,0`。

### 转折点中心

`PCtr` 收不到有效中心时，若最新地图中的 `C/+` 仍位于当前预期 waypoint：

```text
跳过视觉融合
释放当前 waypoint 等待
继续原路径
```

若地图 `C/+` 已不在预期位置，则不能直接放行，应进入第二类重新同步。

### 初次求解和重规划中心

`ICtr` 或 `RCtr` 收不到有效中心时，使用最新合法地图的 `C/+` 格中心：

```text
initial_pose_x_cm = 0
initial_pose_y_cm = 0
```

随后正常求解并启动 executor。

### 返航中心

`RetCtr` 收不到精确中心时，使用出口格 `C/+` 中心和 MCU 里程计继续 Y/X 轴返航。

`RetChk` 收不到精确中心时，只有地图 `C/+` 已位于发车窗口且编码器返航动作正常完成，才允许判定 `Done`。

### 中心与地图冲突

精确中心与合法字符地图冲突时，丢弃精确中心，不得用中心移动字符地图中的 `C/+`。

若字符地图结构合法，则使用地图 `C/+` 和阶段对应的降级策略继续；若字符地图本身也不合法，则进入第二类重新同步。

### 位置修正超时

`VAdj` 或其他中心位置修正超时时，检查当前 pose 到修正目标的剩余轴向误差：

```text
X/Y 误差均不超过 2cm
-> 取消位置修正
-> 保留当前 MCU pose
-> 继续下一阶段

任一轴误差超过 2cm
-> 不直接放行
-> 进入第二类重新同步
```

2cm 复用 `SUBJECT2_FAST_CENTER_TOLERANCE_CM`，不新增另一套容差。

## 视觉 yaw 失败

运动过程中继续以 MCU IMU 为主要 yaw 来源。ART yaw 只在发车区校准和科目二全部观察完成后提供低频辅助。

### 发车 yaw

发车 yaw 样本超时或实际小角修正失败时：

```text
锁定当前 MCU yaw
重建本地 yaw/pose 基准
继续发车
```

不得因为 ART yaw 不可用终止比赛。

### 观察转向

`VTurn` 超时时按当前 MCU yaw 误差处理：

```text
绝对误差不超过 2deg
-> 接受当前朝向
-> 进入分类

绝对误差超过 2deg
-> 当前观察方向标记失败
-> 返回观察规划，尝试该对象其他观察方向
```

超过 2deg 时不能强行分类，避免车头没有正对图案导致错误绑定。

### 恢复发车航向

`HYaw` 超时时：

```text
停止转向
锁定当前 MCU yaw
重置相对 pose 基准
继续选择并执行首次推箱任务
```

锁定当前 yaw 后必须清除旧目标角，避免后续平移时继续追赶已经放弃的发车航向。

### 观察后视觉小角修正

`VYaw/VFix` 超时、样本无效或修正失败时，放弃本次 ART yaw 校准，保留当前 MCU IMU yaw 并继续推箱。

## 精确车箱观察失败

`OBSERVE_SAMPLE` 缺失不等于字符地图中的箱子不存在。处理时必须区分“没有精确数据”和“已经取得冲突证据”。

### 没有精确样本

等待窗口内收不到足够车箱样本，但最新合法地图满足：

```text
C/+ 位于预期推箱准备格
B 位于当前请求箱子格
箱子和目标数量结构合法
```

则执行：

```text
跳过 BGap/BAlign/BNear 精确几何准备
保留 MCU pose
使用 BFS 格点路径继续推箱
```

这种降级状态不再执行 5cm 观察恢复动作，也不进入 `E:BObs`。

### 精确样本显示冲突

若已经收到可信的精确样本，但样本明确表明以下任一情况：

- 小车不在正确推箱侧。
- 箱子已经移动或离开请求格。
- 车箱几何与当前推箱方向矛盾。

则不得忽略证据继续推箱，应停止当前旧路径并进入第二类地图同步和重规划。

## 状态显示

第一类降级不显示 `E:*`。建议复用 Execute 页现有 `S:` 显示短状态：

```text
CtrSkip   精确中心降级
YawKeep   保留 MCU yaw
GridPush  使用格点推箱
```

状态只短暂显示，随后进入 `VTurn`、`Running` 或 `S2Push`。

## 不变范围

- 不修改 BFS 和逐箱贪心策略。
- 不修改 20cm 格距、PID 和 0.5cm 普通到点阈值。
- 不修改 OpenART UART 文本协议。
- 不允许 MCU 根据精确中心移动 ART 字符地图中的 `C/+`。
- 不把地图结构非法、路径不可达或执行器硬件错误降级为继续运动。

## 验收场景

- `VCtr` 无中心时跳过 `VAdj` 并进入 `VTurn`。
- `PCtr` 无中心但地图 C 仍在预期格时继续当前 waypoint。
- `ICtr/RCtr` 无中心时以零 offset 求解和启动。
- `VAdj` 超时且剩余误差不超过 2cm 时继续；超过 2cm 时不放行。
- `VTurn` 超时且 yaw 误差不超过 2deg 时继续分类；超过 2deg 时换观察方向。
- `HYaw/VFix` 失败时锁定当前 MCU yaw 并继续。
- `OBSERVE_SAMPLE` 缺失但 C/B 粗格一致时使用格点路径推箱。
- 精确车箱样本与地图或推箱方向冲突时不得直接放行。
- 所有第一类降级路径均不进入 `EXEC_STATE_ERROR` 或 `SUBJECT2_ERROR`。
