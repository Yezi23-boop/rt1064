# Tag 辅助 OpenART 自动标定备忘

## 核心想法

在屏幕地图四个角墙格内部贴 AprilTag，OpenART 识别 4 个 Tag 中心后，自动建立“标准网格坐标 -> 摄像头图像坐标”的透视变换，用来替代手工调 `MAP_CORNERS`。

## Tag 位置约定

Tag 贴在 16x12 地图外圈四个角墙格内部，四个角格在地图逻辑上仍固定为墙 `#`，识别时直接强制输出墙，不参与颜色分类。

建议 ID 分配：

- ID 0：左上角墙格中心，标准坐标 `(0.5, 0.5)`
- ID 1：右上角墙格中心，标准坐标 `(15.5, 0.5)`
- ID 2：右下角墙格中心，标准坐标 `(15.5, 11.5)`
- ID 3：左下角墙格中心，标准坐标 `(0.5, 11.5)`

## 透视变换方式

不要把 Tag 中心当成地图外边界角点。Tag 中心是角墙格中心，应作为已知网格坐标控制点：

```text
(0.5, 0.5)    -> tag0_center
(15.5, 0.5)   -> tag1_center
(15.5, 11.5)  -> tag2_center
(0.5, 11.5)   -> tag3_center
```

建立变换后，每个格子中心用 `(col + 0.5, row + 0.5)` 投影到图像坐标，再继续沿用当前颜色识别逻辑。

## 运行策略

- 启动或校准阶段连续识别 4 个 Tag。
- 4 个 ID 都齐全后才更新变换。
- 同一 ID 的中心点做 3 帧中值或平均，减少抖动。
- 运行中 Tag 暂时丢失时，继续使用上一套稳定变换。
- 地图识别异常或手动校准时，再触发重新找 Tag。

## 注意事项

- 1cm Tag 可以先试；如果 QVGA 下像素太少导致识别不稳，优先增大到 1.5cm 或 2cm。
- Tag 尽量居中贴在角墙格内，不要压到相邻格子的采样中心。
- Tag 格必须强制识别为墙，避免黑白块污染颜色分类。
- 第一版建议保留手工 `MAP_CORNERS` 作为 fallback，避免 Tag 一时识别不到导致视觉整体不可用。
