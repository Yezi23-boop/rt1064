# 修改轮序排布为 LF, RF, LB, RB

## 目标
将轮序从 `LF=0, LB=1, RF=2, RB=3` 改为 `LF=0, RF=1, LB=2, RB=3`

## 修改文件

### 1. drive_config.h (line 103-110)
修改枚举定义：
```c
typedef enum
{
    WHEEL_LF = 0, /**< 左前轮。 */
    WHEEL_RF,     /**< 右前轮。 */
    WHEEL_LB,     /**< 左后轮。 */
    WHEEL_RB,     /**< 右后轮。 */
} wheel_enum;
```

### 2. base_io.c
修改所有数组顺序为 LF, RF, LB, RB：

**编码器数组 (line 20-42)**
```c

{
    QTIMER2_ENCODER2, // LF

    QTIMER1_ENCODER2, // RB

static const encoder_channel1_enum encoder_ch1[WHEEL_COUNT] =

    QTIMER1_ENCODER2_CH2_C24, // RB

```

**电机数组 (line 44-67)**
